Rhino Player **1.6.1** — Homebrew install plus a PREFIX icons path fix for formula / `.deb` layouts.

### Highlights

- **Homebrew** — `brew install adrianov/rhino-player/rhino-player` (builds from source; depends on GTK 4, libadwaita, mpv)
- **Bundled icons on PREFIX installs** — finds `share/rhino-player/icons` next to `bin/` so symbolic icons work outside a `.app` / checkout

### Download (Assets)

- **`rhino-player_1.6.1-1_amd64.deb`** — Debian / Ubuntu (**x86_64**)
- **`Rhino-Player-1.6.1-macos-arm64.dmg`** — macOS app (**Apple silicon**)

### Install

```sh
brew install adrianov/rhino-player/rhino-player
```

```bash
sudo apt install ./rhino-player_1.6.1-1_amd64.deb
```
